# Base de datos con Docker Compose

Este repositorio contiene base de datos para arracar o levantarlos con `docker compose`

# Requisitos

- Docker Compose version v5.3.1
- Docker version 29.7.0, build c1eba93
- Docker images:
  - postgres:16-alpine
  - mysql:8.4
  - mongo:7.0
